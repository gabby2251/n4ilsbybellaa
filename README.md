# N4ilsByBellaa

A responsive website built for **N4ilsByBellaa**, an independent nail technician. The site provides clients with an easy way to view services, pricing, booking information, policies, and contact details while maintaining a clean, modern design that reflects the business's branding.

## Overview

This project was developed as a custom static website focused on performance, accessibility, and mobile usability. Rather than relying on a website builder, the site is built with standard web technologies for greater flexibility and easier customization.

## Tech Stack

* HTML5
* CSS3
* JavaScript

## Features

* Responsive layout for desktop, tablet, and mobile devices
* Service and pricing pages
* Booking link integration
* Business policies
* Social media links
* Optimized images and fast load times

## Development

Clone the repository and open `index.html` in your browser to view the site locally.

```bash
git clone https://github.com/<username>/n4ilsbybellaa.git
cd n4ilsbybellaa
```

No build tools or package installation are required.

## Purpose

The goal of this project was to create a professional online presence that allows potential clients to quickly find essential business information and book appointments while giving the business owner a website that is simple to maintain and expand over time.
